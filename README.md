# KL Ads — аналитика объявлений Kleinanzeigen

Веб-сервис: лента объявлений с kleinanzeigen.de, динамика цен по срезам, метка «горячих» лотов, фильтры и карточка лота с графиком цены. Работает на **только публичных данных** (без логина в аккаунт).

## Возможности

- 🔍 **Поиск и фильтры** — запрос, диапазон цены, сортировка (горячие / новые / дешевле / дороже / снижение цены), пагинация
- 🔥 **Индикатор «горячих»** — оценка 0–100 по публичным сигналам: снижение цены, новизна, цена против медианы выдачи, теги (Direkt kaufen, Garantie), Topad
- 📈 **История цены** — сервер снимает срезы выдачи и строит график цены по времени (кнопка «↻ Свежий срез» / автообновление раз в 3 мин)
- 🃏 **Карточка лота** — фото, продавец, описание, характеристики, ссылка на оригинал
- 🖼 **Прокси картинок** — изображения отдаются через `/api/img`, поэтому работают везде (превью, хостинг) без CORS/hotlink-проблем
- 🛟 **Демо-режим** — если Kleinanzeigen блокирует IP хостинга (403), интерфейс не падает, а показывает сгенерированные данные; вернувшийся доступ автоматически включает LIVE
- ⏱ **Бережный доступ к Kleinanzeigen** — cookie-сессия, минимум 4 сек между запросами, TTL-кэш 5 мин, повтор при 403 с паузой

> ⚠️ Честно о метриках: Kleinanzeigen **не публикует** просмотры/избранное чужих объявлений. Поэтому «горячесть» и динамика считаются по наблюдаемым данным (цена, дата, позиция, теги). Массовый скрейпинг противоречит условиям сервиса — используйте умеренно, интервалы уже выставлены консервативно.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
```

Переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `KA_MIN_INTERVAL_MS` | `4000` | мин. пауза между запросами к Kleinanzeigen |
| `KA_CACHE_TTL_MS` | `300000` | TTL кэша страниц поиска |
| `DATA_DIR` | `./data` | каталог для history.json |

## Бесплатный хостинг

### Вариант 1 — Render.com (рекомендую, без карты)
1. Зарегистрируйтесь на [render.com](https://render.com) (бесплатный тариф)
2. New → **Web Service** → подключите Git-репозиторий с этим проектом (или используйте «Deploy from GitHub»)
3. Render сам прочитает `render.yaml` (Blueprint): Node, `npm start`, порт берётся из `PORT`
4. Готово — бесплатный инстанс (усыпляется после ~15 мин простоя, первый запрос после пробуждения занимает ~30 сек)

Blueprint-файл уже в репозитории (`render.yaml`).

### Вариант 2 — Railway.app
1. [railway.app](https://railway.app) → New Project → Deploy from repo
2. Команда старта: `npm start` — всё, Railway сам подставит `PORT`

### Вариант 3 — любой VPS / домашний сервер
```bash
npm install && PORT=3000 npm start
```
Рядом можно поставить `pm2`: `pm2 start server.js --name kl-ads`

> Примечание: на датацентровых IP Kleinanzeigen иногда отдаёт 403. Если LIVE не поднимется — сервис продолжит работать в демо/кэш-режиме. Помогает переменная `KA_UA` (свежий User-Agent) и увеличение `KA_MIN_INTERVAL_MS`.

## Структура

```
server.js          — Express: API + статика + прокси картинок
lib/ka.js          — доступ к kleinanzeigen.de (сессия, pacing, кэш, ретраи)
lib/parse.js       — парсеры двух HTML-шаблонов (классический и новый)
lib/store.js       — срезы, история цен, hot-score, тренды
lib/demo.js        — генератор демо-данных
public/            — фронтенд (vanilla JS, без внешних CDN)
data/history.json  — накапливаемая история (создаётся сама)
```

## API

- `GET /api/search?q=iphone+15&min=100&max=800&page=1` — выдача + метрики (`mode`: live/demo/cached)
- `GET /api/ad/:id?href=/s-anzeige/...` — карточка лота
- `GET /api/trending?limit=12` — «разгоняющиеся» лоты
- `GET /api/img?u=<url>` — прокси картинок (только img.kleinanzeigen.de)
- `GET /api/status` — состояние (live/кэш/демо, статистика хранилища)
